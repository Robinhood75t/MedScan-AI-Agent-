# 🏥 MedScan AI Agent

### MedScan AI is an intelligent healthcare assistant that simplifies complex medical reports into easy-to-understand summaries. It helps patients interpret their reports without confusion and provides doctors with a structured overview for faster analysis.

---

## 🚀 Project Overview
MedScan AI allows users to upload medical reports (PDFs or images) and generates a simplified summary using AI.

#### The goal is simple:
Make medical reports understandable for everyone — no medical degree required.
---

## ✨ Key Features

🧾 Report Processing
Upload PDFs or medical images
Extract and process medical data efficiently

#### 🤖 AI-Powered Summarization

Uses Perplexity API for intelligent summarization
Converts complex medical jargon into simple explanations

#### 🌐 Multi-language Support
English 🇬🇧
Hindi 🇮🇳
(More languages planned in future)


#### 👨‍⚕️ Dual Mode System
##### Patient Mode
Easy-to-understand summaries
Focus on clarity and simplicity

##### Doctor Mode
Structured and detailed insights
Helps in quick diagnosis and review


#### 💳 Subscription Model (In Progress)

### ⚙️ Installation & Setup

1️⃣ Clone the Repository
git clone https://github.com/your-username/medscan-ai.git
cd medscan-ai

2️⃣ Setup Backend
cd backend
npm install
npm start

3️⃣ Setup Frontend
cd frontend
npm install
npm start

🔄 How It Works
User uploads a medical report (PDF/Image)
Backend processes and extracts data
Data is sent to Perplexity API

#### AI generates:

Simple summary (Patient Mode)
Detailed structured output (Doctor Mode)
Output is displayed in selected language
